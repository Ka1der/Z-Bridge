# Единое хранилище

При отключённом `AppFeatures.sessionManagementEnabled` приложение запускает `bootstrapLibrary()` и сохраняет новые файлы в `Documents/Downloads`. Активная сессия не создаётся и не восстанавливается. USB и FTP используют общую библиотеку; завершённые передачи учитываются независимо от прежней сессии.

При первом запуске старые папки из `Documents/Sessions` перемещаются целиком в `Documents/Downloads/Imported/<UUID>`. Это сохраняет одноимённые оригиналы, RAW+JPEG и сопутствующие файлы. SQLite обновляет пути, сохраняя идентификаторы, оценки и историю. Журнал `.legacy-migration.json` позволяет продолжить перенос после прерывания между перемещением папки и обновлением базы. При конфликте каталогов запуск передачи останавливается с ошибкой, файлы не перезаписываются.

Старые модели, таблицы и интерфейсы сессий сохранены для совместимости, но недоступны в рабочем режиме. Поле `session_id` у исторических файлов сохраняет происхождение и разделение одноимённых групп; новые файлы используют постоянный идентификатор библиотеки без записи в таблице сессий.

Проверки: `UnifiedLibraryVerificationTests.swift` проверяет миграцию, восстановление после прерывания, коллизии имён, оценки, повторный запуск, общий учёт загрузок и повтор передачи. `TransferOnlyModeVerificationTests.swift` проверяет запуск AppState и блокировку интерфейса сессий.
