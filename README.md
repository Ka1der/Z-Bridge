# NikonZbridge (iOS / iPadOS)

Высокоскоростной мост для мгновенной передачи фотографий (RAW .NEF и JPEG) с камер **Nikon Z** на iPhone и iPad как по проводу (**USB-C / USB-LAN**), так и по воздуху (**Wi-Fi**).

---

## Ключевые возможности

* **Скоростная передача по кабелю (USB-C):** Использование аппаратного режима сетевого адаптера Nikon Z (USB-LAN). Скорость передачи полнокадровых RAW файлов достигает 100–300+ МБ/с.
* **Беспроводная передача (Wi-Fi):** Автоматическая выгрузка кадров сразу при спуске затвора (Shoot-to-iPad).
* **Zero-Copy потоковая запись:** Сетевые данные пишутся напрямую на диск блоками до 256 КБ, исключая переполнение оперативной памяти устройства при непрерывной серийной съемке.
* **Мгновенное превью RAW:** Извлечение встроенного превью из заголовков `.NEF` через `ImageIO` (задержка отображения < 30 мс).
* **Адаптивный UI для iPadOS и iOS:** Полноэкранный просмотрщик кадра с зумом, инспектор метаданных EXIF (ISO, выдержка, диафрагма, фокусное расстояние) и сетка сессии.

## Настройка камеры Nikon Z

### Вариант 1. По кабелю USB-C (Рекомендуется для максимальной скорости)
1. Соедините камеру Nikon Z и iPad / iPhone 15+ кабелем USB-C $\leftrightarrow$ USB-C.
2. В меню камеры: **Меню настройки** (иконка ключа) ➔ **USB** ➔ выберите **«Компьютер»** или **«USB-LAN»**.
3. В **Меню сети** (иконка антенны) ➔ **«Подключение к FTP-серверу»** ➔ **«Параметры сети»** ➔ выберите проводной интерфейс.
4. Создайте профиль FTP:
   * **Тип сервера:** FTP
   * **Адрес сервера:** IP-адрес из карточки приложения (с пометкой `USB-LAN`)
   * **Порт:** `2121`
   * **Логин/Пароль:** можно оставить пустыми (или ввести любые)
5. Включите **«Автоматическая отправка»** ➔ **ВКЛ**.

### Вариант 2. По воздуху (Wi-Fi)
1. Подключите камеру и iPad/iPhone к одной Wi-Fi сети (или к точке доступа смартфона).
2. В **Меню сети** ➔ **«Подключение к FTP-серверу»** укажите IP-адрес Wi-Fi из приложения и порт `2121`.
3. Кадры передаются автоматически при каждом нажатии кнопки спуска.
