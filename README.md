# Z-Bridge (iOS / iPadOS)

**Z-Bridge** — профессиональное приложение для фотографов, обеспечивающее надежный tethering и мгновенный прием фотографий (RAW `.NEF`, JPEG, HEIF) с беззеркальных камер **Nikon Z** на iPad и iPhone как по кабелю (**USB PTP/MTP** и **USB-LAN**), так и по беспроводной сети (**Wi-Fi**).

Проект спроектирован с акцентом на абсолютную сохранность оригиналов, непрерывную работу в условиях студийных съемок, отбор и выставление оценок (Culling), экспорт в целевые редакторы через XMP-сайдкары и вывод чистого изображения клиенту (Client Monitor).

---

## Ключевые возможности и архитектура

### 1. Двухканальный прием данных (Transports)
* **Проводной USB (MTP / PTP):** Прямое подключение по кабелю Type-C через `ImageCaptureCore` с поддержкой скачивания по инициативе приложения и обнаружения снимков на карте памяти камеры.
* **Сетевой FTP-сервер (Wi-Fi / USB-LAN / Ethernet):** Высокопроизводительный сервер на базе `Network.framework`, реализующий стандарты RFC 959 и RFC 2428:
  - Пассивные режимы передачи: `PASV` и расширенный `EPSV`;
  - Мульти-интерфейсная маршрутизация (раздельное определение IP для Wi-Fi `en0` и проводных USB-LAN `en*`);
  - Управление доступом: валидация учетных данных через `FTPAuthManager`, ограничение максимального числа клиентов и переключатель приема.

### 2. Гарантия сохранности данных (Data Integrity)
* **Двухфазная запись через Staging:** Входящие файлы принимаются потоковыми блоками во временную директорию `.staging/transfer_<jobID>_*.tmp`.
* **Атомарная финализация:** Перенос в каталог сессии выполняется методом атомарного перемещения только после проверки целостности (сигнатура TIFF/JPEG и размер).
* **Не перезаписываемые оригиналы:** При совпадении имен файлов автоматически формируются суффиксы `_1`, `_2` без перезаписи существующих данных.
* **Защита свободного места (`DiskSpaceGuard`):** Контроль дискового пространства перед началом приема и экспорта с блокировкой операций при приближении к аварийному порогу.
* **Восстановление после аварий (`DiskCatalogReconciler`):** Автоматическая очистка осиротевших staging-файлов и постановка на учет файлов на диске, если процесс был прерван до фиксации в каталоге.

### 3. Каталогизация, отбор и группировка кадров (Culling)
* **Локальная база данных SQLite (`CatalogDatabase`):** Хранение сессий, ассетов, метаданных EXIF и очереди переносов.
* **Объединение в пары RAW+JPEG / HEIF:** Автоматическая группировка парных снимков (`CaptureGroup`) с поддержкой позднего прихода компаньона.
* **Рейтинги и отметки:** Оценки от 0 до 5 звезд, статусы «Выбрано» (`Picked`) и «Отклонено» (`Rejected`).
* **Аппаратные горячие клавиши iPad:** Управление отбором с клавиатуры (`1–5`, `P`, `X`, `U`, стрелки навигации, `Пробел`).
* **Сравнительный просмотр 2-up:** Режим одновременного сравнения двух кадров с синхронным зумом и панорамированием.

### 4. Экспорт и XMP-метаданные
* **Пакетный экспорт (`ExportManager`):** Экспорт в системные папки, внешние SSD (с обработкой Security-Scoped Bookmarks), медиатеку «Фото» и меню «Поделиться».
* **Генерация XMP Sidecar:** Экспорт оценок и меток в сайдкары `.xmp` с готовыми профилями совместимости для **Adobe Lightroom**, **Capture One** и **Photo Mechanic**.
* **Абсолютная неизменность RAW:** Файлы оригиналов остаются байт-в-байт идентичными (контроль по SHA-256), сайдкары сохраняются рядом.
* **Манифесты сессии:** Формирование файлов `session_manifest.json` и удобочитаемых отчетов `session_report.md`.

### 5. Клиентский монитор (Client Monitor)
* **Минималистичный интерфейс:** Полноэкранный показ последнего кадра без служебных панелей.
* **Фильтрация:** Возможность показа только отобранных кадров (`Picked`).
* **Внешний экран iPadOS:** Поддержка отдельного представления для клиентов на внешнем мониторе (HDMI / Type-C / AirPlay) с сохранением панели управления у фотографа.

```

├── App/

│   ├── Metadata/                       # Генерация XMP и профили совместимости
│   ├── Models/                         # Доменные модели (MediaAsset, CaptureGroup, Job)
│   ├── Network/                        # FTP-сервер, сокеты и USB-LAN монитор
│   ├── Storage/                        # StorageManager, DiskSpaceGuard, Reconciler
│   └── Transports/                     # Адаптеры транспортов (USB, FTP)
├── UI/                                 # Интерфейс SwiftUI (Dashboard, Gallery, Detail, Sheets)
├── Tests/                              # Автоматические верификационные тесты (Этапы 1–13)
└── HARDWARE_MATRIX.md                  # Матрица аппаратной совместимости
```

## Системные требования

* **Устройство:** iPad (рекомендуются модели с USB-C / Thunderbolt и процессорами M-серии) или iPhone (iOS 16.0+).
* **Инструменты разработки:** macOS 14.0+, Xcode 15.0+, Swift 5.9+.
* **Камеры:** Nikon Z 9, Z 8, Z 6 III, Z f, Z 7 II, Z 6 II, Z 5, Z 50, Z 30, Z fc (подробности в [HARDWARE_MATRIX.md](HARDWARE_MATRIX.md)).

## Результаты замеров производительности (Apple Silicon)

* **Скорость финализации и хеширования SHA-256:**
  - 10 МБ JPEG: **> 600 МБ/с** (время обработки: ~0.016 с);
  - 45 МБ RAW `.NEF`: **> 750 МБ/с** (время обработки: ~0.060 с).
* **Задержка отображения превью:** Первичное декодирование embedded preview из заголовка `.NEF` занимает **~90 мс**, повторный показ из кэша — **< 10 мс**.
* **Потребление оперативной памяти:** При пакетном приеме серии из 10 тяжелых RAW-файлов (150 МБ данных) прирост Resident Set Size составил менее **38 МБ** за счет блочной потоковой записи.
* **Отзывчивость UI:** Фоновые дисковые и криптографические операции вызывают задержку главного потока не более **1.5 мс**, сохраняя плавность анимации 60/120 FPS.

## Известные платформенные ограничения iOS / iPadOS

1. **Фоновая работа приложения (Background Execution):**
   - iOS может приостановить выполнение приложения в фоновом режиме через определенное время после сворачивания, если не активна фоновая сессия. Рекомендуется держать приложение на экране во время активной непрерывной съемки.
2. **Безопасный доступ к внешним накопителям (Security-Scoped Bookmarks):**
   - Доступ к папкам на внешних SSD осуществляется через закладки безопасности `URL.startAccessingSecurityScopedResource()`. При физическом отключении SSD во время трансфера система прерывает запись; локальные файлы при этом не страдают.
3. **Питание для Lightning-устройств:**
   - Для стабильной работы проводного соединения с iPhone/iPad на разъеме Lightning требуется оригинальный адаптер Apple Lightning to USB 3 Camera Adapter с обязательным подключением внешнего питания от 12W.
